# Cybersecurity SOC & System Security Labs

### Hands-On Cybersecurity Portfolio | SOC Operations | Threat Detection | Windows Security

Welcome to my cybersecurity home lab portfolio!

This repository documents my hands-on cybersecurity projects focused on Security Operations Center (SOC) analysis, security monitoring, Windows system security, incident investigation, and vulnerability management.

My goal is to develop and demonstrate practical technical skills relevant to **SOC Analyst, Cybersecurity Analyst, and System Security roles**.

---

## About This Portfolio

This portfolio is organized around four enterprise-inspired cybersecurity labs designed to demonstrate the ability to:

- Configure and monitor security infrastructure.
- Collect and analyze Windows and Linux security logs.
- Investigate suspicious activities and security alerts.
- Secure Windows Server and Active Directory environments.
- Develop SIEM detection rules and investigative queries.
- Identify, prioritize, and remediate security vulnerabilities.
- Document technical findings and security recommendations.

Each project will include practical configurations, screenshots, investigation results, and lessons learned as the work progresses.

## Lab 01 — Enterprise SOC Monitoring & Threat Detection

**Objective:** Build a security monitoring environment to collect, analyze, and investigate endpoint security events.

**Planned activities:**
- Configure a security monitoring platform.
- Collect Windows security events using Sysmon and an appropriate log collector.
- Generate safe, controlled security test events.
- Investigate suspicious PowerShell execution and authentication activity.
- Develop and validate detection rules.
- Map relevant findings to MITRE ATT&CK.
- Document a simulated SOC investigation.

**Skills demonstrated upon completion:** SIEM monitoring, log analysis, threat detection, alert triage, and security reporting.

**Status:** Planned

## Lab 02 — Active Directory Security & Windows Server Hardening

**Objective:** Build and secure a Windows Active Directory environment.

**Planned activities:**
- Install and configure Windows Server.
- Deploy Active Directory Domain Services.
- Create organizational units, users, and security groups.
- Implement Group Policy security settings.
- Configure password and account lockout policies.
- Audit privileged accounts and authentication events.
- Validate security hardening configurations.

**Skills demonstrated upon completion:** Active Directory administration, identity and access management, Windows security, and system hardening.

**Status:** Planned

## Lab 03 — Microsoft Sentinel SOC Investigation

**Objective:** Investigate security events using Microsoft Sentinel and Kusto Query Language.

**Planned activities:**
- Configure a Sentinel lab or use an appropriate controlled dataset.
- Explore authentication and security telemetry.
- Write KQL queries to identify suspicious activities.
- Investigate simulated security incidents.
- Develop detection queries and document findings.
- Prepare an incident investigation report.

**Skills demonstrated upon completion:** Cloud SIEM, KQL, security analytics, incident investigation, and reporting.

**Status:** Planned

## Lab 04 — Vulnerability Management & Remediation

**Objective:** Perform an authorized vulnerability assessment and document remediation.

**Planned activities:**
- Configure isolated lab systems.
- Conduct network discovery and vulnerability scanning.
- Analyze findings and assess security risks.
- Prioritize remediation activities.
- Apply security patches and configuration improvements.
- Perform follow-up scans to validate remediation.
- Prepare a vulnerability assessment report.

**Skills demonstrated upon completion:** Vulnerability assessment, risk prioritization, remediation, system hardening, and technical reporting.

**Status:** Planned
